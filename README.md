# Android Apps

This repository is a workspace for multiple independent Android projects. Each
app lives in its own directory with its own Gradle wrapper and documentation.

## Projects

- [`AndroidMirror/`](AndroidMirror/) — parked Android Auto phone-screen mirroring
  (formerly ParkedPhotos/Phone Mirror)

- [`IMAXTracker/`](IMAXTracker/) — an Android client that requests live Harkins
  IMAX seat scans from a Raspberry Pi over Tailscale
- [`AndroidAutoTemplate/`](AndroidAutoTemplate/) — a local-development starter
  for projected Android Auto apps using the Car App Library

The downloaded JDK, Android SDK, Gradle distribution, build outputs, and IDE
files are excluded from Git by the root `.gitignore`.
